## 済んでいること（サイト内）

2026.07.08 に実施。

- Hero の h1 を「札幌チェスクラブ」という連続した文字列として読めるようにした
- About セクションを新設し、社会人・サークル・シニアなどの言葉を本文に入れた

## 残っていること（サイト外）

サイト内は整備済みで、残る主因はドメインの若さと被リンクの少なさ。コードを触っても動かない。

- Search Console でインデックス状況と検索語ごとの表示回数を確認する
- Google ビジネスプロフィールに登録する
- 旧掲示板・mixi から新サイトへリンクを張ってもらう

## 依頼が来たときの進め方

- まず Search Console の実データを見る。順位が低い理由を推測で直さない
- 言葉を足す場所は About（`src/i18n/ja.ts` の `about`）と meta description
- **クラブの実態と食い違う言葉を足さない**。以前、検索向けに誇張した文言を書いて訂正された。守る事実は [AGENTS.md](../AGENTS.md) の「文言を書くとき」
